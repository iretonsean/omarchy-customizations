My Workspace

On a Mac keyboard, Super is the ⌘ key. Each kind of work has its own workspace. Use the Projects menu to open your work. You do not have to type commands.

Start work on a project

  1. Press Super D to open the Projects menu.
  2. Select a project.
  3. Select Agent session to start a session with your coding agent in that project. The session opens on the project's workspace.

Each project can also have site rows. They open a website of the project as an app on the project's workspace. Each project has Folder (opens the file manager) and Terminal too.

The coding agent is the one you set with omarchy default agent.

Your projects

To add or change a project, edit ~/.config/omarchy/projects.json, then run projects-apply in a terminal.

Dock

The dock is at the bottom of the screen. It hides until you move the pointer to the bottom edge.

  • Items: T3 Code, Claude, Terminal, Files, Chromium, Figma, Paper, Claude Design, Projects, your project sites, HEY, WhatsApp, Obsidian.
  • A dot under an icon shows that the app is running. Click it to go to its window.
  • The grid button on the right opens all apps.
  • Change the items: edit ~/.config/nwg-dock-hyprland/pinned (one app per line), then run projects-apply. Project sites are added after Projects.

T3 Code

T3 Code shows your coding agent sessions in a window. It uses the agents you already have installed and signed in to.

  1. The first time you open it, click through the Connect screen.
  2. Add your project folders as projects.
  3. You can run several sessions at the same time, one for each task.

Theme: Graphite

Graphite is your own theme. It uses dark neutral grays, a blue accent, 12px rounded corners, soft shadows and no blur.

  • Fonts: SF Pro in menus and apps such as Files. SF Mono in the terminal and the bar.
  • Cursor: the pre-Tahoe macOS cursor theme, from the apple_cursor package. A white version, "macOS-White", is also installed.
  • Change the background: press Super Ctrl Space. There are two backgrounds, "glow" and "plain".
  • Change the theme: press Super Shift Ctrl Space. To go back to the old look, select Matte Black.
  • Theme files: ~/.config/omarchy/themes/graphite/

Where the files are

  • Projects: ~/.config/omarchy/projects.json
  • Workspace rules: ~/.config/hypr/workspaces.lua
  • Keys: end of ~/.config/hypr/bindings.lua
  • Menus: ~/.config/omarchy/extensions/omarchy-menu.jsonc
  • This guide: ~/.local/share/workspace-guide/index.html

To undo

Remove require("hypr.workspaces") from ~/.config/hypr/hyprland.lua, and remove the "Projects menu" lines at the end of bindings.lua and of the menu file.
