My Workspacesuper k

On a Mac keyboard, super is the ⌘ key. Each kind of work has its own workspace. Use the Projects menu to open your work. You do not have to type commands.

Start work on a project3
1Open the Projects menusuperd
2Select a project
3Select Agent session

The session opens on the project's workspace, with the coding agent that you set with omarchy default agent. Each project also has site rows, which open a website of the project as an app, and Folder and Terminal rows.

Your projectsprojects.json

To add or change a project, edit ~/.config/omarchy/projects.json, then run projects-apply in a terminal.
